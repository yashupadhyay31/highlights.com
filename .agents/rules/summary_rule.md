# Task Summary Rule

After performing any task, ALWAYS provide a clear and structured summary covering:
1. **Root Cause of the Error / Problem**: What caused the issue in the code, data, or configuration.
2. **How the Task Was Performed & Solved**: A step-by-step breakdown of how the changes were made, including files updated and logic applied.
3. **Verification**: How the fix was verified or instructions on how to test it.
